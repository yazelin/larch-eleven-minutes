## 1. 目標與限制

- 長度 8～10 分鐘。使用 RPG 擴充（地圖、事件、道具、任務提示）＋一組自製插件。
- 每條路徑都要能走到結局，不能因為被抓、打錯指令、字被沒收而卡死。
- 不打怪：所有地圖 `combat:"none"`。被巡邏兵看到＝送回檢查點，不扣血。
- 評分五項（主題契合、創意、美術、沉浸感、完成度），另有「最佳 RPG 玩法」獎，玩法要明顯用到 RPG 系統，不能只是對話卡。

## 2. 世界觀（寓言化）

| 寓言名 | 意象 | 在遊戲裡 |
|---|---|---|
| 龍城 | 牆內的國家 | 機房地圖。整齊、紅色警示燈、每條走廊都有規則 |
| 長牆 | 網路長城 | 地圖北緣一道發光的鎖鏈牆，挑戰主視覺的「天空鎖鏈」 |
| 鷹雲 | 牆外的自由網路 | 雲海地圖。開闊、沒有牆，但有看不見的東西 |
| 稜鏡之眼 | 牆外的監聽 | 雲海裡飄著的玻璃眼睛，不擋路，只會看 |
| 推薦藤 | 牆外的演算法 | 雲海的藤蔓，會把信往熱鬧的方向拉 |

主角：**小封**，一隻發光的信鴿，是一個資料封包。名字同時是「封包」和「封鎖」的封。
寄信人：龍城裡的女孩**禾禾**（暫名），寫信給在鷹雲的朋友。信的全文到結局才揭曉。

## 3. 主題怎麼對上「自由與限制」

| 挑戰頁的鎖 | 位置 | 玩家實際碰到的事 |
|---|---|---|
| 看得見的鎖 | 龍城機房 | 巡邏兵、關鍵字過濾門會沒收信裡的字、長牆擋住出口 |
| 看不見的鎖 | 鷹雲 | 沒人擋路，但推薦藤把信拉走，稜鏡之眼一直在看。自由也有代價 |
| 心裡的鎖 | 結局前 | 信可以送出了，禾禾的手指停在「撤回」上。玩家替她決定 |

作品的回答：牆可以翻過去，但沒有人替你按下送出。結局 B（撤回）是自我審查，牆其實已經不在了。

貫穿線：**信紙 HUD**。畫面角落一張小信紙，被沒收的字變成「□」，玩家隨時看得到信被削掉多少。

## 4. 遊戲流程

```
序章（文字卡）：禾禾寫信、按下送出，信變成一隻鴿子
 └ 龍城機房（地圖 1）
    ├ 撿字：信裡的五個字散在機房，撿回來
    ├ 過濾門 ×2：帶敏感字過門會被沒收 → 找「諧音小販」改寫
    ├ 巡邏兵：被看到送回檢查點
    └ 長牆前的伺服器 →［終端機卡］翻牆
       └ 鎖鏈斷開（過場）
          └ 鷹雲（地圖 2）
             ├ 推薦藤：走錯路被拉去熱鬧區（不卡死，繞回來）
             ├ 稜鏡之眼：對話，看不見的鎖
             └ 收信人的窗前 → 分支（禾禾的手指停在撤回）
                ├ 送出 → 結局 A：信被讀到，全文揭曉（缺的字照樣是 □）
                └ 撤回 → 結局 B：鴿子散成光點，回到窗前可重選
```

### 4.1 龍城機房（約 4 分鐘）
1. 任務提示「把散掉的字撿回來」。五個字是道具：`字·自由`、`字·真相`、`字·名字`（敏感）、`字·想你`、`字·晚安`（不敏感）。暫定，作者定稿。
2. **過濾門**：touch 事件，背包有敏感字就沒收（`removeItem` 之前先確認數量），旁白「這個字不能過去。」，信紙 HUD 對應位置變成 □。不卡死，只是信變少。
3. **諧音小販**（NPC）：可以把敏感字換成隱喻字（`自由→雲`、`真相→天氣`、`名字→小名`），換過的字過門不會被沒收。這就是牆內人說話的方式，本身也是一種限制。
4. **巡邏兵**：NPC 照路線走。看到主角就送回最近的檢查點。實作方式要先驗證（§8）。
5. **VPN 鑰匙**：藏在機房角落的道具「隧道鑰匙」，終端機卡要用。

### 4.2 終端機卡（約 2 分鐘，自製插件卡）
仿終端機畫面，鍵盤和觸控都能用（手機給指令按鈕，不必真打字）。
1. `ping 鷹雲` → 逾時。提示「好像有東西擋著。」
2. `traceroute 鷹雲` → 一跳一跳走，最後一跳停在「長牆」。
3. `tunnel --key 隧道鑰匙` → 沒有鑰匙會提示回去找（回地圖，主角留原格）；有鑰匙就連線成功。
4. `send` → 鎖鏈斷開，complete。
- 打錯兩次就跳出提示；`help` 隨時可以叫。不會卡死。
- 讀 `has_key`，寫 `tunnel_ok`。

### 4.3 鷹雲（約 3 分鐘）
1. 開場過場：鎖鏈一節一節斷開，雲海展開，BGM 從壓抑換成開闊。
2. 沒有牆、沒有巡邏。推薦藤在幾條路口，走過去會被拉到「熱鬧區」（一群喊口號的鴿子），出口繞回主路。
3. 稜鏡之眼：對話，「我不攔你，我只是看著。」
4. 收信人的窗前：觸發分支。

### 4.4 結局
- **A 送出**：信被讀到，全文顯示。被沒收的字是 □、改寫過的字是隱喻字。收信人的回信只有一句（新寫）。
- **B 撤回**：禾禾按下撤回，鴿子散成光點。旁白點出牆已經不在了。結束畫面提供「回到窗前」。

## 5. 變數

| 變數 | 值 | 用途 |
|---|---|---|
| `phase` | `collect`／`wall`／`cloud`／`window` | 任務提示與事件開關 |
| `lost_*` | true／false | 五個字各自有沒有被沒收（HUD 與結局讀） |
| `alias_*` | true／false | 敏感字有沒有改寫 |
| `has_key` | true／false | 隧道鑰匙 |
| `tunnel_ok` | true／false | 終端機卡結果 |
| `caught` | 數字 | 被巡邏兵抓到幾次（旁白可用） |
| `ending` | `""`／`A`／`B` | 分支 |

## 6. 自製插件 `cloud-war`

- **信紙 HUD**：讀 `lost_*`、`alias_*`，顯示五格字，沒收的變 □，改寫的換字。`interactive:false`。
- **終端機卡**：見 §4.2。
- 沿用《起跑總在開始前》的規則：`pluginWriteVars`／`pluginReadVars` 要列全；一定送 `larch:complete`；手機可操作；深淺色都看得清楚。

## 7. 美術與音樂

- 畫風（2026-10-08 作者：像素或賽博）：建議**像素霓虹**，像素小人＋霓虹光。龍城用紅色警示燈，鷹雲用藍白色的雲光。光影用地圖 `environment.lights` 與 `fog` 做，不畫死在圖上。UI 風格用 Larch 官方介面「**霓虹訊號**」（作者 2026-10-08 指定）：深色玻璃面板、青色與洋紅霓虹、掃描線、切角外框；標題像舊螢幕開機、收到訊號才穩定；鎖住的選項標 LOCKED；背包是右邊滑出的資料面板；CG 收藏是監視器牆，未解鎖的畫面是 NO SIGNAL；RPG 暫停選單是滿版 HUD 加底部工作列。附標題音樂與互動音效。地圖與插件卡（信紙 HUD、終端機卡）的配色要跟它對齊：青色＝鷹雲，洋紅／紅＝龍城。
