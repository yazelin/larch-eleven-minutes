# 配音表（2026-10-09 準備）

只配角色台詞（引號裡的話），旁白不配。台詞一律從 `canon/原文.md`、`canon/新寫.md` 取；畫面上的字不動，唸錯的字用同音字替身（照 tts skill）。

## 怎麼掛進遊戲

- 對話卡（序、審訊室、結局）：每一句台詞的 `voiceUrl`。
- 地圖上的對話（十九樓、雲端）：在那句 `dialogue` 步驟前面插一個 `sound` 步驟（引擎沒有地圖對話的語音欄位，`sound` 帶網址可以播）。
- 戰鬥中的台詞（大肥魚半血那兩句）：戰鬥觸發的 `lines`，要再查能不能帶聲音；不行就只配地圖上的版本。
