# 配音表（2026-10-09 準備）

只配角色台詞（引號裡的話），旁白不配。台詞一律從 `canon/原文.md`、`canon/新寫.md` 取；畫面上的字不動，唸錯的字用同音字替身（照 tts skill）。

## 怎麼掛進遊戲

- 對話卡（序、審訊室、結局）：每一句台詞的 `voiceUrl`。
- 地圖上的對話（十九樓、雲端）：在那句 `dialogue` 步驟前面插一個 `sound` 步驟（引擎沒有地圖對話的語音欄位，`sound` 帶網址可以播）。
- 戰鬥中的台詞（大肥魚半血那兩句）：查過引擎，戰鬥觸發的 `lines` 只吃講者、文字、圖，不吃聲音，所以遊戲裡這兩句沒有配音（音檔有生，審稿頁聽得到）。
- 審訊室的對話卡是演在地圖上的，引擎在地圖上不播對話卡的 `voiceUrl`，所以拆成一句一張、每句前面插 `sound`。

## 正式配音（10-09）

`python3 voice/gen.py`：走 larch-tts-bridge（.11:8072，Larch 語音），三條平行，每個角色一支聲線＋預設情緒，個別句子在 `EMO` 另外指定情緒。輸出 `assets/voice/*.mp3` 與 `voice/manifest.json`（段落 → 音檔），`src/build.py` 照 manifest 掛進遊戲。

`python3 voice/review.py` → `voice/review.html`：完整劇本照遊戲順序排，有配音的段落旁邊有播放器、角色、聲線、情緒。在 repo 根目錄開 `python3 -m http.server`，打開 `/voice/review.html`。

好幾個人搶著說的段落列在 `CROWD`（每句晚幾秒進來、疊著播，同一時間最多兩個人；河城群聲 0.5 秒）。聲線在 `voice/gen.py` 的 `VOICE`，情緒在 `EMO`；聲線寫 `edge:<聲線>` 就改走 edge-tts（PRISM 用小臻 zh-TW-HsiaoChenNeural，沒有情緒參數，自己壓 -18 LUFS）；改完重跑 gen.py（只重生改到的句子）→ build → push。

## 試聲（舊，edge-tts）

`python3 voice/cast.py` → `voice/cast/index.html`：每個角色用 edge-tts 中國普通話聲線各試兩種。定了聲線以後再決定正式引擎（edge-tts 直接用，或拿挑定的那支當參考音給本機 CosyVoice3 做 zero-shot）。
